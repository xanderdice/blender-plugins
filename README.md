# blender-plugins

Add-ons de Blender de **xander.dice**.

| Add-on | Qué hace |
| --- | --- |
| [Meldra](meldra/) | Suelda, cierra y valida mallas para que el Decimate no abra agujeros y los pesos automáticos funcionen a la primera |
| [Atlara](atlara/) | Funde los materiales de varios objetos en un solo atlas y un solo material, para gastar el mínimo de drawcalls en el motor de juego |

Cada carpeta trae su propio `README.md`, sus pruebas y un
`empaquetar.bat` que genera el zip instalable.
